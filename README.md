# Übungen: Claude im Arbeitsalltag

Unterlagen für die Übungen eines eintägigen Seminars zu Claude (claude.ai). Alle Dokumente beschreiben einen **erfundenen Fall**; Organisationen, Anbieter, Preise und Termine sind ausgedacht.

## Herunterladen

1. Oben auf dieser Seite **Code** wählen, dann **Download ZIP**.
2. Die ZIP-Datei entpacken.
3. Im entpackten Ordner `LABS.md` öffnen (im Browser auf dieser Seite lesbar, auf dem Rechner mit jedem Texteditor).

Ein Git-Programm brauchen Sie nicht.

## Inhalt

| Datei oder Ordner | Wofür |
|---|---|
| `LABS.md` | die Übungen |
| `fall/` | Fallunterlagen S01 bis S05 und S07 (Word, PDF, Excel) |
| `spaeter/` | Unterlage S06, erst auf Aufforderung öffnen |
| `prompt-vorlagen.md` | Startsammlung für Ihre eigene Prompt-Bibliothek |
| `wiki-vorlage.md` | Vorlage für die Wiki im Project |
| `pruefcheckliste.md` | Checkliste, bevor Sie ein Ergebnis weitergeben |
